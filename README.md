
## Lost In Translation
Hello! This is Lost in Translation, an language learning adventure game. 

## Architecture and Considerations
This will eventually be intergrated into a fully language learning platform. However, the interactive experience was designed to be fully client side.
1. The client gets immediate feedback, and once the experience is downloaded dodgy internet won't cut them off.
2. The server doesnt need to concern itself with the interactive experiences, minimizing requests.
3. The client gets a responsive single page app with no critical client data, while the server can keep a secure perimeter and handle logins.
